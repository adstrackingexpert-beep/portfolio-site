GTM Web & Server Container তৈরি

Google Tag Manager-এ নতুন Web Container তৈরি করা হয়। এখানেই সব browser এবং সার্ভার-সাইড ট্যাগ, ট্রিগার ও প্যারামিটার কনফিগার করা হয় যাতে অ্যাডস প্ল্যাটফর্মে ডাটা পাঠানো যায়।

২

আপনার নিজের ডোমেইনে (same-origin path বা সাবডোমেইন) ট্র্যাকিং এন্ডপয়েন্ট তৈরি করা হয়। এতে অ্যাড ব্লকার ও Safari ITP বাইপাস হয়।

৩

Cloudflare দিয়ে Proxy

Cloudflare-এ কাস্টম সার্ভার বানিয়ে GTM-এর সাথে কানেক্ট করা হয়। কোনো আলাদা সার্ভার বা মাসিক খরচ লাগে না।

৪

ওয়েবসাইটের Web Container থেকে Cloudflare Server-এ ইভেন্ট পাঠানোর কনফিগারেশন করা হয় এবং ডাটা ফ্লো সেটআপ করা হয়।

৫

Clients ও Conversion API সেটআপ

GA4 Client, Meta CAPI, TikTok Events API, Google Ads Enhanced Conversions ইত্যাদি Cloudflare Server-এ যোগ ও কনফিগার করা হয়। Event Match Quality সর্বোচ্চ রাখা হয়।

Event ID দিয়ে Client + Server ডুপ্লিকেট আটকানো হয়। Preview Mode, DebugView ও রিয়েল টেস্টিং করে নিশ্চিত করা হয় সব ইভেন্ট সঠিকভাবে যাচ্ছে।

সাধারণ প্রশ্ন (FAQ)

সার্ভার-সাইড ট্র্যাকিং কী?

ব্রাউজারের বদলে আপনার নিজস্ব সার্ভার থেকে Meta, Google ও TikTok-এ ইভেন্ট পাঠানোর পদ্ধতি। এতে অ্যাড ব্লকার ও ব্রাউজার রেস্ট্রিকশনে ডাটা কম হারায়।

আমার ওয়েবসাইট Shopify / WordPress / কাস্টম হলে চলবে?

হ্যাঁ। WordPress, WooCommerce, Shopify, কাস্টম কোডেড সাইট এবং ল্যান্ডিং পেজে সেটআপ করা যায়। প্ল্যাটফর্ম অনুযায়ী পদ্ধতি একটু আলাদা হয়।

সেটআপের পর কি মাসিক খরচ আছে?

আমার সার্ভিস ফি এককালীন। Stape-এর মতো মাসিক সার্ভার ফি নেই। আপনার দৈনিক অ্যাড বাজেট যদি ১,০০০ USD হয়, তাহলে Cloudflare-এর মাসিক ৫ USD-এর প্ল্যান কিনতে হবে। এর আগে কোনো প্ল্যান ছাড়াই ফ্রিতে প্রিমিয়াম সব সুবিধা পাবেন।

কুকি ও প্রাইভেসির বিষয়টা কী?

ফার্স্ট-পার্টি ডোমেইনে ট্র্যাকিং চলে, ফলে কুকি দীর্ঘস্থায়ী হয়। ইউজারের কনসেন্ট ও প্রাইভেসি নিয়ম মেনে চলার দায়িত্ব আপনার সাইটের কনসেন্ট সেটিংসের সাথে যুক্ত থাকে।

কাজ শেষে কি আমি নিজে ম্যানেজ করতে পারব?

হ্যাঁ। সব অ্যাকাউন্ট আপনার নামে থাকে এবং সম্পূর্ণ ডকুমেন্টেশন দেওয়া হয়।
